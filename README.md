# Habit Tracker App

A simple and lightweight habit tracking application built with **FastAPI** (backend) and a basic frontend.  
This project helps users create habits, mark them as complete, and track progress over time.

---

## 🚀 Features
- Add new habits with name and frequency
- View all habits in a list
- Mark habits as completed
- Track streaks and progress
- Easy to extend with reminders and statistics

---

## 🛠 Tech Stack
- **Backend:** FastAPI (Python)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite (optional, for persistence)
